Privacy Policy — Reel Publisher (TikTok Integration)

Last updated: 2026-11-09

1. What data this application accesses

When the operator authorizes the application with TikTok, the application receives and stores:

  • the OAuth access token and refresh token issued by TikTok;
  • the TikTok account identifiers returned by the API: open_id, union_id, username, display name, and avatar URL;
  • the content being published: the video file, its title/description, and the posting settings (privacy level, duet/stitch/comment flags).

No other personal data, contact lists, messages, or browsing activity are accessed.

2. Where the data is stored

All data stays on the operator's own computer: a local PostgreSQL database, a local Redis instance, and the local filesystem, all bound to the local machine. There is no cloud backend, no third-party analytics, no advertising, and no data broker.

3. How the data is used

The data is used only to authenticate with TikTok, upload the video, publish the post, and read back the resulting post status and basic statistics.

4. Sharing

Nothing is shared with third parties. The only outbound transmission is to TikTok's official API (open.tiktokapis.com), which is required in order to publish the content. Data is never sold.

5. Retention

OAuth tokens are kept until the operator disconnects the integration or revokes access from the TikTok account settings. Post records and video files are kept locally for as long as the operator chooses, and can be deleted at any time by the operator.

6. Security

The application runs on a single machine and its services are reachable only from that machine. API credentials are kept in local configuration files that are excluded from version control.

7. Rights and deletion

Authorized access can be revoked at any time from TikTok's settings (Settings and privacy → Security and login → Manage app permissions). Revoking access invalidates the stored tokens; the remaining local records can be deleted by the operator at any time.
